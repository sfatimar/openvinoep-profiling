# openvinoep-profiling

This repository is created to provide built-in scripts and documentation for OpenVINO Execution Provider Profiling. 

  
  1. Latency Profiling
     Operator Profiling details can be enabled through [ONNXRuntime Profiling](https://onnxruntime.ai/docs/performance/tune-performance/profiling-tools.html)
  2. Power Measurement through VTune Profiler
  3. OpenVINO Detailed Profiling Tools
